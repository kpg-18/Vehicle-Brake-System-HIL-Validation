# Vehicle Brake System HIL Validation

## Real-Time Brake Control, Safety Validation, and ADAS Fault Analysis

### Project Overview
This project develops a real-time Hardware-in-the-Loop (HIL) brake system simulation for automotive safety validation. It models brake pedal input, vehicle speed, ECU response, actuator behavior, fault injection, and a prototype lane-keep assist function. The project is structured around a MATLAB/Simulink-inspired model and includes a dashboard for live monitoring and analysis.

### Key Highlights
- Real-time brake pedal and ECU interaction model
- ADAS-relevant fault injection scenarios
- Brake pressure and latency analysis
- CAN bus communication mock
- Lane-keep assist prototype logic
- Simulink-inspired system architecture
- GUI-based monitoring dashboard

### Challenges Addressed
- Safety-critical brake performance under variable conditions
- System behavior during sensor and actuator faults
- Response latency and timing sensitivity in automotive control
- Integration of ADAS logic with braking functions

### Impact
The project demonstrates how HIL principles can be used to evaluate system reliability, safety response, and functional behavior before full vehicle-level deployment. It aligns with the practices used in modern brake and ADAS validation engineering.

### Tools and Methodology
- Python-based simulation environment
- Model-based design structure
- Fault analysis and performance monitoring
- GUI-driven interaction for live system review

### Project Value
This work is suitable for academic submissions, automotive engineering portfolios, and technical presentations focused on embedded systems, vehicle safety, and ADAS validation.
