# Vehicle Brake System HIL Validation

## Real-Time Brake Control, Safety Validation, and ADAS Fault Analysis

-------------------------------------------

### Automotive Embedded Systems | HIL Simulation | ECU Validation | ADAS Safety

-------------------------------------------

This project demonstrates a real-time vehicle brake system simulation developed in a MATLAB/Simulink-inspired architecture, integrating brake pedal response, ECU behavior, fault injection, latency analysis, and lane-keep assist prototyping for ADAS-focused validation.
