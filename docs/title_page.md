# Vehicle Brake System HIL Validation

## Real-Time Simulation for Safety-Critical Brake and ADAS Validation

Prepared for: Automotive Systems and ADAS Validation Portfolio

Student / Developer: Kruparth Prakash Gowda

Date: 2026-08-30

---

### Project Overview
This project focuses on the development of a real-time Hardware-in-the-Loop (HIL) brake system simulation for evaluating vehicle deceleration, ECU behavior, brake actuator response, and ADAS-relevant fault scenarios. The work is structured to emulate automotive validation workflows used in safety-critical systems and driver-assistance development.

### Core Objectives
- Develop a real-time brake system HIL model
- Validate ECU response under dynamic braking conditions
- Measure system latency and braking performance
- Simulate fault states relevant to ADAS safety validation
- Prototype lane-keep assist logic in the control loop

### Technology Stack
- Python-based simulation framework
- MATLAB/Simulink-inspired model structure
- CAN bus communication mock
- Real-time monitoring dashboard
- Fault injection and safety evaluation logic

### Engineering Relevance
This project aligns with automotive engineering practices used in brake-by-wire development, ECU validation, functional safety analysis, and ADAS control verification.
